# CodeAlpha Task 2 - Unemployment Analysis with Python

### Intern: Maryam Tuba | Data Science Internship

**Objective:** Analyze COVID-19 impact on Unemployment in India (2019-2020).

**Dataset Used:** Unemployment in India dataset (CMIE)

**Tools & Libraries:**
- Python, Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- Jupyter Notebook

**Analysis Steps (6 Steps):**
1. Data Loading & Cleaning
2. Labor Participation Rate (39.88% vs 41.21%)
3. Region-wise Analysis (Urban vs Rural)
4. Peak Lockdown Shock - 21.81% in Apr 2020
5. State-wise Highest Impact - Puducherry 70.5%
6. Recovery Trends Visualization

**Key Insights:**
- Urban areas faced "Severe Stoppage" during lockdown
- Rural sectors recovered faster due to Farming & Relief
- Visual Dashboard created using React + Tailwind for presentation
